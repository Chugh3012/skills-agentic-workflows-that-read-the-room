## Awesome Copilot workflows worth trying

- [Daily Issues Report](https://github.com/github/awesome-copilot/blob/main/workflows/daily-issues-report.md) — a scheduled daily summary of open issue activity.
- [Relevance Check](https://github.com/github/awesome-copilot/blob/main/workflows/relevance-check.md) — a `/relevance-check` slash command that flags whether an issue or PR is still relevant.
- [Weekly Comment Sync](https://github.com/github/awesome-copilot/blob/main/workflows/weekly-comment-sync.md) — finds stale code comments and README text and proposes fixes via a draft PR.
